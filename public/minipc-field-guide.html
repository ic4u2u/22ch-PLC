PART 1

미니PC에 우리 모니터링 프로그램 설치하기 (출발 전 인터넷 되는 곳에서 1회)

  1. Node.js 설치 (이미 깔려 있으면 패스): 👉 https://nodejs.org/ko 에서 초록색 LTS 버전 다운 → [다음 → 다음 → 설치]
  2. 프로그램 폴더 준비: 용주가 전달한 프로젝트 폴더(PLC_24CH_Monitoring_System)를 미니PC 바탕화면(또는 C:\PLC)에 복사합니다.
  3. 최초 1회 설치 실행: 폴더 안에 있는 1_최초설치_미니PC_1회실행.bat 파일을 더블클릭합니다.
    • 검은 창이 뜨고 자동으로 필요한 패키지를 설치합니다 (약 1~2분 소요).
    • "[설치 완료!]" 메시지가 뜨면 창을 닫습니다. (이제 현장 인터넷이 없어도 작동합니다!)
PART 2

[출발 전 연습] 미니PC 혼자 '가상 PLC'로 시뮬레이션 돌려보기

광주 업체에 가기 전, 미니PC에서 우리 프로그램이 정상 작동하는지 가상 PLC와 연결해 미리 확인하는 단계입니다.

  1. 폴더 안의 2_시뮬레이션모드_가상PLC_테스트실행.bat 파일을 더블클릭합니다.
  2. 검은 창이 켜지면서 ① 가상 PLC 서버(127.0.0.1:8502) + ② 브릿지 서버 + ③ 3D 관제 화면이 동시에 켜집니다.
  3. 약 5초 뒤 자동으로 브라우저가 열리며 http://localhost:3000 화면이 뜹니다.
  4. 확인할 것:
    • 11종 가스(22개 3D 가스통) 압력 숫자가 실시간으로 들어오고, 공급중인 가스통에 애니메이션이 잘 나오는지 확인!
    • 하단 상태 바에 "정상 연결"이 뜨는지 확인!
  5. 확인이 끝나면 검은 창을 닫아 종료합니다.
PART 3

[실전] 경기도 광주 업체(컨트롤러 회사)에서 실물 PLC와 연결하기

📌 3-1. 광주 업체 PLC 개발자에게 딱 이 표만 보여주세요! (가장 중요 ⭐)

우리 모니터링 프로그램은 아래 약속(메모리 번지)대로 PLC에서 22개 압력과 밸브 값을 읽어옵니다. 업체 PLC 담당자에게 이 표를 보여주면 1분 만에 맞춰줍니다.

통신 방식 (둘 다 지원)압력값 22채널 (1차측 압력 × 10)밸브 상태 22채널 (0=닫힘, 1=열림)포트 번호
LS XGT 전용 프로토콜 (권장) %MW100 ~ %MW121 (22워드) %MW200 ~ %MW221 (22워드) TCP 2004
Modbus TCP (스마트 서버) Holding Reg 0 ~ 21 (40001~40022) Holding Reg 100 ~ 121 (40101~40122) TCP 502
💡 압력 숫자 규칙: 예를 들어 48.6 Bar이면 PLC 메모리에는 소수점 없이 10을 곱한 정수 486을 넣어주시면 됩니다. (만약 업체 번지가 다르면 번지표 사진만 찍어 용주에게 카톡으로 보내주면 원격으로 5분 만에 수정 가능!)

📌 3-2. 미니PC와 PLC 랜선 연결 & IP 맞추기

  1. 미니PC와 광주 업체 PLC(또는 허브)를 랜선으로 연결합니다.
  2. 업체 PLC IP가 예를 들어 192.168.1.10이면, 미니PC IP도 앞 3자리를 똑같이 맞춥니다:
    제어판 → 네트워크 및 공유 센터 → 이더넷 → 속성 → IPv4 → 다음 IP 주소 사용
    • IP 주소: 192.168.1.11  |  서브넷 마스크: 255.255.255.0  |  게이트웨이: 192.168.1.1
  3. Ping 연결 확인: 윈도우 키 → cmd 입력 후 아래 명령어 실행 → 시간<1ms가 뜨면 랜선 연결 100% 성공!
    ping 192.168.1.10

📌 3-3. (1차 점검) 패킷이 진짜 오가는지 10초 확인하기 (선택)

바로 본 화면을 켜기 전에 패킷 덤프부터 눈으로 보고 싶으면:

  1. tools \ xgt-ethernet-tester \ 2_PC_B_클라이언트실행(EnetClient).bat 더블클릭
  2. 브라우저(http://localhost:3100)에서 PLC IP(192.168.1.10), 포트 2004 → [🔌 연결] → [📥 읽기 요청] 클릭!
  3. 우측 창에 TX / RX HEX 패킷이 들어오면 통신 100% 성공! (창을 닫고 아래 3-4로 이동)

📌 3-4. (최종 실전) 우리 22채널 3D 모니터링 시스템에 실물 PLC 연결!

  1. 프로젝트 폴더의 3_현장실물PLC연결_광주업체_테스트실행.bat 파일을 더블클릭합니다.
  2. 검은 창이 물어보는 2가지만 입력하고 엔터:
    • 통신 방식: XGT면 1 (엔터), Modbus면 2 입력
    • PLC IP 주소: 예) 192.168.1.10 입력 후 엔터
  3. 약 5초 뒤 http://localhost:3000 3D 관제 화면이 열리며, 광주 업체 PLC의 실제 압력/밸브 값이 화면에 실시간 반영됩니다!
🎉 테스트 성공 기준: 업체 개발자가 PLC의 %MW100 값을 바꾸거나 밸브(%MW200)를 켜고 끌 때, 우리 3D 화면의 1번 가스(고순도메탄 A) 숫자와 공급 애니메이션이 0.5초 안에 같이 움직이면 완벽 성공입니다!
