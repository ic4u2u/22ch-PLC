🔌 LS XGT 이더넷 통신 테스터 초간단 설치·실행 가이드

카톡으로 받은 ZIP 압축 파일만 풀어서 3분 만에 PC ↔ PC 및 현장 실물 LS PLC(TCP 2004) 통신 테스트를 실행하는 안내서입니다.

STEP 1

Node.js 설치 (PC당 최초 1회, 1분 컷)

이 프로그램을 실행할 노트북·미니PC에 Node.js가 없다면 먼저 설치하세요. (이미 설치되어 있으면 STEP 2로 바로 이동!)

1. 아래 공식 사이트 접속 👉 https://nodejs.org/ko
2. 초록색 LTS (권장 버전) 버튼 클릭해 다운로드
3. 설치 파일 실행 후 [다음 → 다음 → 설치]만 누르면 완료!
🔌 현장 필수 체크: 노트북에 유선 랜선(RJ45) 포트가 없다면 USB-to-LAN 유선랜 젠더를 꼭 준비해 주세요!
STEP 2

카톡으로 받은 ZIP 파일 압축 풀기

  1. 카톡으로 받은 xgt-ethernet-tester.zip 파일을 바탕화면(또는 원하는 폴더)에 저장합니다.
  2. 파일에 마우스 우클릭 → [압축 풀기]를 눌러 폴더를 엽니다.
✅ 별도 설치 과정 0분! 압축만 풀면 1_PC_A_서버실행(가상PLC).bat과 2_PC_B_클라이언트실행(EnetClient).bat 파일이 바로 보입니다.
STEP 3

상황별 실행 방법 (더블클릭만 하면 끝!)

① 내 PC 혼자 사전 테스트 (10초)

  1. 1_PC_A_서버실행(가상PLC).bat 더블클릭
  2. 2_PC_B_클라이언트실행(EnetClient).bat 더블클릭 → 브라우저 자동 열림
  3. IP 127.0.0.1 / 포트 2004 그대로 두고 [🔌 연결] → [📥 읽기 요청] 클릭
  4. 우측 창에 TX / RX HEX 패킷과 수신값 486이 뜨면 성공!

② PC 2대 간 이더넷 테스트

  1. 두 PC를 같은 공유기(또는 랜선 직결)로 연결
  2. PC A에서 1번 .bat 실행 → 방화벽 창 뜨면 [액세스 허용] 클릭! 화면에 표시된 PC A IP 주소 확인
  3. PC B에서 2번 .bat 실행 → 대상 IP에 PC A IP 입력 후 [🔌 연결]
  4. XGT 읽기/쓰기 또는 하단 자유 텍스트 전송으로 송수신 확인!
STEP 4

광주 현장 실물 LS PLC 연결 방법 (TCP 2004)

실물 PLC와 연결할 때는 1번 .bat은 끄고, 2번 .bat만 실행하시면 됩니다.

  1. 랜선 연결: 노트북/미니PC와 현장 PLC(또는 허브)를 랜선으로 연결합니다.
  2. PC IP 맞추기 (LS 매뉴얼 3p 기준): PLC IP가 192.168.1.10이면 내 PC IP도 앞 3자리를 똑같이 맞춥니다.
    제어판 → 네트워크 및 공유 센터 → 이더넷 → 속성 → IPv4 → 다음 IP 주소 사용
    • IP 주소: 192.168.1.11  |  서브넷 마스크: 255.255.255.0  |  게이트웨이: 192.168.1.1
  3. 연결 확인(Ping): 윈도우 키 → cmd 입력 후 아래 명령어 실행 → 시간<1ms 뜨면 랜선/IP 연결 100% 성공!
    ping 192.168.1.10
  4. 패킷 테스트: 2_PC_B_클라이언트실행(EnetClient).bat 더블클릭 → PLC IP(192.168.1.10), 포트 2004 입력 → [🔌 연결] → %MW0 [📥 읽기 요청] 클릭!
  5. 문제가 생기면 우측 하단 [📋 카톡 전달용 로그 복사] 버튼을 눌러 카톡으로 그대로 보내주세요.
