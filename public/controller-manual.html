2. 기본 조작법 및 에러 코드

  • 수동 강제 정지 / 해제: Up 버튼과 Down 버튼을 동시에 2초 이상 누르면 모든 밸브가 닫힙니다. 다시 2초 이상 누르면 원상 복귀됩니다.
  • 알람 소리 끄기: 알람이 울릴 때 아무 버튼이나 1회 누르면 소리가 꺼집니다.
  • 메뉴 진입: Mode 버튼을 2초 이상 누릅니다.
  • 메뉴 이동: Mode 버튼을 누르면 좌측 메뉴번호에 점(예: S-01.)이 들어옵니다. 이때 Up / Down으로 메뉴를 이동합니다.
  • 설정값 선택 & 변경: Set 버튼을 누르면 우측 설정값에 점(예: 3.)이 들어옵니다. Up / Down으로 값을 변경합니다.
  • 설정값 저장: 값을 바꾼 뒤 Set 버튼을 다시 누르면 우측 창에 0.이 들어오면서 저장됩니다.
  • 메뉴 종료: 메뉴 선택 상태에서 Mode 버튼을 2초 이상 누르거나, 10분 동안 아무 조작이 없으면 자동 종료됩니다.

5. 웹 관제 앱에서 컨트롤러 설정하는 방법

  1. 관리자 잠금 해제: 앱 상단 우측의 [🔒 잠금] 버튼을 눌러 관리자 PIN(기본 1234)을 입력해 잠금을 해제합니다.
  2. 컨트롤러 설정 탭 이동: 상단에서 [🎛️ 관제(제어·시험) 시스템] → [🎛️ HW-2601A 컨트롤러 설정] 탭을 클릭합니다.
  3. 뱅크 선택: 1번 ~ 11번 뱅크 중 설정을 변경할 뱅크(컨트롤러)를 선택합니다.
  4. 가상 FND 패널 또는 카드에서 설정 변경:
    • 상단의 가상 HW-2601A 전면 패널에서 실물과 똑같이 Mode / Set / Up / Down 버튼을 눌러 조작해 볼 수 있습니다.
    • 아래 카드 목록에서 S-03(A 압력 최대값: 초기 160 bar, 설정 범위 20 ~ 300 bar)처럼 숫자를 입력하고 [적용](또는 11개 전체에 똑같이 넣으려면 [전체적용])을 누릅니다.
    • 허용 범위를 벗어난 숫자를 입력하면 빨간색 경고 메시지가 표시되며, 적용 시 자동으로 안전 범위 내로 보정됩니다.
  5. 대시보드 즉시 반영: S-03/04(최대압력), S-05/06(교체압력), S-07(Ready압력), S-10(단위), S-11(모드), S-13/14(밸브동작시간 4.0~8.0초)을 변경하면 앱의 실린더 게이지와 자동절체 기준에 즉시 반영되고 서버 DB에 자동 저장됩니다.
