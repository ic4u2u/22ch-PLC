1. 핵심 업그레이드 5대 요약

업그레이드 ①

🎛️ HW-2601A 컨트롤러 설정 & 가상 패널

메뉴얼.txt의 S-01~S-20(사용자), H-01~H-09(시스템) 설정과 허용 범위를 웹 앱에 그대로 탑재했습니다.

  • 실물과 동일한 3개 FND 표시창(메뉴번호·보기·설정값) + 4개 버튼(Mode·Set·Up·Down) 시뮬레이터 제공
  • 예: S-03 A압력 최대값 초기 160 bar / 설정 20 ~ 300 bar 범위 자동 검증
  • 밸브 동작시간 4.0 ~ 8.0초, 교체압력 2 ~ 250 bar 즉시 대시보드 반영
업그레이드 ②

📘 A/B 자동절체 제어 우측 [매뉴얼 파일] 버튼

관제시스템 → A/B 자동절체 제어 상단 바 맨 오른쪽에 📘 매뉴얼 파일 버튼을 추가했습니다.

  • 클릭 즉시 인터넷 없이도 매뉴얼.txt 원문과 그림·표 통합 설명서를 바로 열람 가능
  • public/manual.txt 및 public/controller-manual.html 로컬 탑재
업그레이드 ③

⏳ PLC 미연결 시 11개 뱅크 (초기화 중) 표시

SW 처음 구동 시 PLC와 통신이 연결되기 전까지 거짓 '정상' 표시 대신 명확한 대기 상태를 표시합니다.

  • 간편모니터링(와이지원 뷰): 11개 뱅크 카드 하단 배지 → ⏳ 초기화 중
  • 기본 월보드 뷰: 상단/하단 상태 배너 → ⏳ 초기화 중 (PLC 연결 대기)
  • PLC 연결 즉시 실제 상태(✅ 정상, ⚠️ 주의 등)로 자동 전환
업그레이드 ④

📡 XGT 가상 PLC 22워드(76B) 연속 응답 지원

가상 PLC(tools/xgt-ethernet-tester)가 1워드(34B)만 응답해 0.0 bar로 나오던 문제를 해결했습니다.

  • %MB200(압력 22W), %MB400(밸브 22W) 연속 읽기(0x0014) 시 76 Bytes 정상 응답
  • Word 1 ~ Word 22 실제 압력/밸브 상태 즉시 수신 확인 가능
업그레이드 ⑤

💾 오프라인 100% 동작 & USB 포터블 호환

모든 매뉴얼·컨트롤러 설정·가상 PLC 기능이 외부 인터넷 없이 로컬 및 USB 포터블 환경에서 동작합니다.

  • 0_오프라인_USB포터블_패키지_만들기.bat 실행 후 USB에 복사하면 현장 PC 무설치 실행

⚠️ C:\Users\800G4> 기본 폴더에서 git pull을 치면 not a git repository 오류가 납니다. 반드시 프로젝트 폴더로 이동하거나 아래처럼 새로 받으세요.

npm run build
