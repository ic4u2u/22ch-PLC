[ACSC 22채널 관제] 장비 개봉부터 조립·결선·XG5000 입력까지
그대로 따라 하는 실전 세팅 마스터 가이드

구입하신 본체 1대 + 확장 모듈 5개(아날로그 3개, 릴레이 1개, 이더넷 1개)가 도착했을 때, 초보자도 순서대로 따라 하면 15분 만에 개통할 수 있는 전 과정 매뉴얼입니다.

① XBC-DR30SU (×1개)
메인 CPU + 밸브 1~12번
② XBF-AD08A (×3개)
1~3단: 압력센서 22채널
③ XBE-RY16A (×1개)
4단: 밸브 13~22번
④ XBL-EMTA (×1개)
5단: 미니PC 랜선 통신
STEP 1 (필수)

합체하기 전에! [XBF-AD08A × 3개] 옆면 스위치를 '전류(I)'로 올리세요

⚠️ 조립 전 무조건 1순위 작업! (안 하면 압력값이 0으로 나옵니다)
XBF-AD08A 모듈 3개를 박스에서 꺼내면, 본체 옆면에 하얀색 작은 스위치 8개(CH0~CH7)가 있습니다.
공장 출고 시에는 전압(V, 아래쪽)으로 내려가 있으니, 레고처럼 합체하기 전에 작은 드라이버나 볼펜 끝으로 3개 모듈 모두 스위치 8개를 전부 [I (전류, 위쪽)] 방향으로 딸깍 올려주세요!
STEP 2

6개 블록 레고 합체 순서 (왼쪽 0번 본체 ➔ 오른쪽 1~5번 슬롯)

1
측면 작은 뚜껑 열기: 각 모듈의 오른쪽 옆면에 있는 작은 플라스틱 덮개(증설 커버)를 손톱이나 일자 드라이버로 톡 떼어냅니다. (맨 마지막 5단 XBL-EMTA의 오른쪽은 그대로 막아둡니다.)
2
순서대로 끼우기: 왼쪽부터 [본체 XBC-DR30SU] ➔ [1단 AD08A] ➔ [2단 AD08A] ➔ [3단 AD08A] ➔ [4단 RY16A] ➔ [5단 XBL-EMTA] 순서로 핀을 맞춰 수평으로 밀어 넣습니다.
3
위·아래 잠금 후크 딸깍 잠그기: 모듈 위쪽과 아래쪽에 있는 회색 고정 레버(후크)를 본체 쪽으로 딸깍 소리가 나게 밀어 완전히 잠급니다.
STEP 3

단자대 전선 연결 도면 (어느 나사에 어떤 선을 물리나요?)

1번 나사 (CH0)1번 압력센서 신호선 (+)
2번 나사 (CH1)2번 압력센서 신호선 (+)
3번 나사 (CH2)3번 압력센서 신호선 (+)
4번 나사 (CH3)4번 압력센서 신호선 (+)
5번 나사 (COM)센서 공통 마이너스 (- / 0V)
6번 나사 (CH4)5번 압력센서 신호선 (+)
7번 나사 (CH5)6번 압력센서 신호선 (+)
8번 나사 (CH6)7번 압력센서 신호선 (+) *(3단은 비움)*
9번 나사 (CH7)8번 압력센서 신호선 (+) *(3단은 비움)*
10번 나사 (24V)⚡ 외부 DC 24V 파워 (+) 필수 연결!
11번 나사 (G)⚡ 외부 DC 24V 파워 (- / 0V) 필수 연결!
⚡ [본체 + 4단] 22개 솔레노이드 밸브 결선 총 22개 밸브

[본체 하단] P44 ~ P47 (4개)밸브 CH05 ~ CH08 (+)선 연결
[본체 하단] P48 ~ P4B (4개)밸브 CH09 ~ CH12 (+)선 연결
[4단 RY16A] 00 ~ 09 (10개)밸브 CH13 ~ CH22 (+)선 연결
[4단 RY16A] 0A ~ 0F (6개)예비 출력 (비워둠)
[모든 출력 공통] COM0, COM1...⚡ 외부 DC 24V 파워 (+) 공통 연결
[밸브 반대쪽 선] 밸브 (-)선⚡ 외부 DC 24V 파워 (- / 0V) 공통 연결
STEP 4

XG5000 프로그램 세팅 (클릭 순서 그대로 따라 하기)

💻 준비물: LS ELECTRIC 공식 홈페이지(ls-electric.com) 자료실에서 무료 XG5000 (한국어판)을 미니 PC(또는 노트북)에 설치하고, XBC-DR30SU 왼쪽 아래 뚜껑을 열어 Mini-USB 5핀 케이블로 PC와 연결한 뒤 전원을 켭니다.
1
새 프로젝트 만들기: XG5000 실행 ➔ 상단 [프로젝트] → [새 프로젝트] 클릭 ➔
• 프로젝트 이름: ACSC_22CH
• CPU 시리즈: XGB / CPU 종류: XGB-XBCU (또는 XBC-SU 표준형 / XBC-DR30SU) 선택 후 [확인]
2
5단 모듈 1초 만에 자동 인식시키기 (I/O 동기화):
• 상단 메뉴 [온라인] → [접속] 클릭 (USB로 바로 연결됨)
• 상단 메뉴 [온라인] → [진단] → [I/O 정보] 클릭 ➔ 팝업창에서 [I/O 동기화] 버튼 클릭!
• 그러면 옆에 끼운 1~5단 모듈(AD08A×3, RY16A×1, EMTA×1)이 자동으로 촤르륵 등록됩니다!
3
1~3단 압력센서 모듈(XBF-AD08A) 스케일 설정 (0 ~ 1500 = 0.0 ~ 150.0 bar):
• 왼쪽 트리에서 [I/O 파라미터] 더블클릭 ➔ 1번, 2번, 3번 슬롯의 XBF-AD08A를 각각 클릭하고 아래 표처럼 똑같이 맞춥니다:
⚙️ XG5000 - [I/O 파라미터] ➔ 슬롯 1, 2, 3 (XBF-AD08A) 채널 설정값 CH0 ~ CH7 전체 체크
파라미터 항목 선택할 설정값 왜 이렇게 설정하나요?
채널 운전 상태 (CH0~CH7) 사용 (Enable) 슬롯1(CH0~7), 슬롯2(CH0~7), 슬롯3(CH0~5) 사용 켜기
입력 범위 (Input Range) 4 ~ 20 mA 4mA 미만의 단선(0mA) 감지를 위해 반드시 4~20mA 선택
출력 데이터 타입 사용자 정의 스케일 (또는 0~16000 기본값) 스케일 하한값: 0 / 스케일 상한값: 1500 (= 150.0 bar) 설정
4
5단 이더넷 모듈(XBL-EMTA) 고정 IP 설정 (192.168.0.50):
• 왼쪽 프로젝트 트리에서 [내장/외장 통신 파라미터] → 슬롯 5번 [XBL-EMTA (FEnet)] 더블클릭
• IP 주소: 192.168.0.50 / 서브넷 마스크: 255.255.255.0 / 게이트웨이: 192.168.0.1 입력
• 전용 서비스 / 모드버스(Modbus TCP) 서버 설정: 활성화 체크 (모드버스 워드 읽기/쓰기 기본 영역을 M 영역 M0000으로 지정)
STEP 5

XG5000 래더(Ladder) 프로그램 입력 — 딱 이대로 넣으세요!

왼쪽 프로젝트 창에서 [NewProgram] → [프로그램]을 더블클릭한 뒤, 1~3단 압력센서 22개 값을 %MW100 ~ %MW121(M0100 ~ M0121)에 담아두고, 미니 PC가 보낸 %MW200 ~ %MW221(M0200 ~ M0221) 밸브 차단 신호로 실제 릴레이를 켜고 끄는 코드입니다.

// [1] 상시 ON 접점(F00099)으로 매 스캔마다 22채널 압력값을 M0100~M0121 (%MW100~%MW121)로 복사 |--[ F00099 ]------------------------------------------------[ BMOV U01.02 M0100 8 ]--| // 1단 AD08A (CH01~CH08) ➔ %MW100~%MW107 | [ BMOV U02.02 M0108 8 ]--| // 2단 AD08A (CH09~CH16) ➔ %MW108~%MW115 | [ BMOV U03.02 M0116 6 ]--| // 3단 AD08A (CH17~CH22) ➔ %MW116~%MW121 // [2] 미니 PC 밸브 제어 명령(%MW200~%MW221 : 1이면 차단 코일 구동) ➔ 본체 12점(P0040~P004B) & 4단 모듈(P0080~P0089) 출력 |--[ > M0200 0 ]--------------------------------------------( P0040 )--| // CH01 밸브 (본체 출력 1번) |--[ > M0201 0 ]--------------------------------------------( P0041 )--| // CH02 밸브 (본체 출력 2번) // ... (동일 패턴으로 M0202~M0211 ➔ P0042~P004B 본체 12점 연결) ... |--[ > M0212 0 ]--------------------------------------------( P0080 )--| // CH13 밸브 (4단 RY16A 출력 1번) // ... (동일 패턴으로 M0213~M0221 ➔ P0081~P0089 4단 모듈 10점 연결) ... |------------------------------------------------------------[ END ]----|
💡 마지막 저장(PLC 쓰기) 방법:
입력 완료 후 XG5000 상단 메뉴 [온라인] → [쓰기] 클릭 ➔ [프로그램 + 파라미터] 모두 체크 후 [확인]을 누르고, PLC 상태를 [RUN 모드]로 바꾸면 PLC 세팅이 100% 끝납니다! (이제 USB 케이블은 뽑으셔도 됩니다!)
STEP 6

상황실 미니 PC 랜선 연결 및 원클릭 실행 (3분 완성)

1
랜선 & USB 경광등 연결: 5단 XBL-EMTA의 랜포트와 상황실 미니 PC 랜포트를 CAT.6 랜선으로 연결하고, 미니 PC의 USB 포트에 USB 3색 타워램프를 꽂습니다.
2
미니 PC 고정 IP 자동 세팅: 프로젝트 폴더의 set-plc-ip.bat와 allow-firewall.bat를 마우스 우클릭 → [관리자 권한으로 실행] 합니다. (미니 PC IP가 자동으로 192.168.0.100으로 세팅됩니다.)
3
관제 시스템 가동!: start-dual-kiosk.bat를 더블클릭하면 1번 모니터(조작 대시보드)와 2번 대형 TV(22채널 전광판)가 켜지며 실시간 22채널 압력과 밸브 제어가 즉시 작동합니다!
