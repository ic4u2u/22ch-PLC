# 🔌 LS XGT 이더넷 통신 테스터 (PC ↔ PC / 실물 PLC)

LS ELECTRIC 공식 매뉴얼(`Ethernet 전용 프로토콜 통신 방법`, TCP 2004, `LSIS-XGT`) 규격에 맞춰 **PC 2대 간 이더넷 데이터 송수신** 및 **현장 실물 PLC 연결 테스트**를 1분 만에 수행할 수 있는 초간단 독립형 SW입니다.

> **장점**: 외부 패키지 설치(`npm install`)가 전혀 필요 없습니다! Node.js만 설치되어 있으면 이 폴더(`xgt-ethernet-tester`)를 USB나 카톡으로 다른 PC에 복사해서 `.bat` 파일만 더블클릭하면 바로 실행됩니다.

---

## 1️⃣ PC 1대(혼자)에서 먼저 10초 테스트하기
1. `1_PC_A_서버실행(가상PLC).bat` 더블클릭 → 검은 창에 `TCP 2004 대기` 확인
2. `2_PC_B_클라이언트실행(EnetClient).bat` 더블클릭 → 브라우저(`http://localhost:3100`) 자동 실행
3. IP `127.0.0.1`, 포트 `2004` 그대로 두고 **`[🔌 연결 (Connect)]`** 클릭 → 초록불 **`연결됨`** 확인
4. **`[📥 읽기 요청 (Read)]`** 클릭 → 우측 패킷 덤프 창에 `TX` / `RX` HEX와 수신값 `486 (48.6)` 확인!
5. 하단 텍스트 입력창에서 **`[전송]`** 클릭 → PC A에서 받아서 되돌려주는 응답 확인!

---

## 2️⃣ PC 2대(용주 PC ↔ 정호 PC)에서 이더넷 통신 테스트하기
1. **네트워크 연결**: 두 PC를 같은 공유기(와이파이/허브)에 연결하거나 랜선으로 1:1 직결합니다.
   - 1:1 랜선 직결 시: PC A IP를 `192.168.1.10`, PC B IP를 `192.168.1.11` (서브넷 마스크 `255.255.255.0`)로 수동 설정
2. **PC A (가상 PLC 역할)**: `1_PC_A_서버실행(가상PLC).bat` 실행
   - Windows 방화벽 팝업이 뜨면 반드시 **`[액세스 허용]`** 클릭!
   - 화면에 표시된 PC A의 IPv4 주소(예: `192.168.1.10`) 확인
3. **PC B (테스트 클라이언트 역할)**: `2_PC_B_클라이언트실행(EnetClient).bat` 실행
   - 대상 IP에 **PC A의 IP 주소** 입력, 포트 `2004` → **`[🔌 연결]`** 클릭 후 송수신 테스트!

---

## 3️⃣ 경기도 광주 현장 실물 LS PLC와 바로 연결하기
PC 2대 테스트가 끝나면, **PC A를 끄고 실물 LS PLC(XBL-EMTA / XGL-EFMT)로 바꾸기만 하면 됩니다.**
1. PC B(노트북)를 현장 PLC와 랜선으로 연결하고, 같은 대역 IP(예: `192.168.1.11`) 설정
2. `2_PC_B_클라이언트실행(EnetClient).bat` 실행
3. 대상 IP에 **현장 PLC IP(예: `192.168.1.10`)**, 포트 **`2004`** 입력 → **`[🔌 연결]`**
4. `%MW0` 또는 업체 번지표의 주소(예: `%MW100`)를 입력하고 **`[📥 읽기 요청]`** 클릭!
5. 안 되거나 값이 이상하면 우측 하단 **`[📋 카톡 전달용 로그 복사]`**를 눌러 그대로 공유하면 즉시 분석 가능합니다.
