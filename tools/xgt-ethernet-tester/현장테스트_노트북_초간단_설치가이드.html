STEP 1

프로그램 내려받기 (둘 중 편한 방법 1개 선택)

✅ 방법 A. Git 명령어로 5초 만에 받기 (추천)

바탕화면에서 마우스 우클릭 → 터미널에서 열기(또는 윈도우 키 → cmd 실행) 후 아래 명령어 복사·붙여넣기:

git clone https://github.com/ic4u2u/22ch-PLC.git

※ 이미 폴더가 있는 PC에서 최신 버전으로 업데이트할 때는 폴더 안에서 아래 명령어만 입력:

cd 22ch-PLC && git pull origin main

✅ 방법 B. Git 없이 웹에서 ZIP 파일로 받기 (가장 쉬움)

  1. 브라우저에서 👉 https://github.com/ic4u2u/22ch-PLC 접속
  2. 초록색 [<> Code] 버튼 클릭 → 맨 아래 [Download ZIP] 클릭
  3. 다운로드된 ZIP 파일의 압축을 풀면 22ch-PLC-main 폴더 생성 완료!
STEP 2

XGT 이더넷 통신 테스터 바로 실행 (설치 과정 0분!)

💡 핵심 장점: 통신 테스터 폴더(tools\xgt-ethernet-tester)는 npm install이 전혀 필요 없습니다. Node.js만 있으면 더블클릭으로 즉시 켜집니다!

탐색기에서 22ch-PLC \ tools \ xgt-ethernet-tester 폴더를 여세요.

  1. 혼자 사전 테스트할 때 (PC 1대):
    • 1_PC_A_서버실행(가상PLC).bat 더블클릭 → 검은 창에 TCP 2004 대기 확인
    • 2_PC_B_클라이언트실행(EnetClient).bat 더블클릭 → 브라우저(http://localhost:3100) 자동 열림
    • IP 127.0.0.1 / 포트 2004 그대로 두고 [🔌 연결] → [📥 읽기 요청] 클릭하여 TX/RX 패킷 확인!
  2. PC 2대 간 이더넷 테스트할 때:
    • PC A에서 1번 .bat 실행 → 화면에 뜨는 PC A의 IP 주소 확인 (방화벽 창 뜨면 [액세스 허용] 클릭!)
    • PC B에서 2번 .bat 실행 → 대상 IP에 PC A IP 입력 후 [🔌 연결] 클릭
STEP 3

현장 실물 LS PLC 연결 방법 (TCP 2004)

  1. 랜선 연결: 노트북/미니PC와 현장 PLC(또는 허브)를 랜선으로 연결합니다.
  2. PC IP 맞추기 (LS 매뉴얼 3p 기준): PLC IP가 192.168.1.10이면 내 PC IP도 앞 3자리를 똑같이 맞춥니다.
    제어판 → 네트워크 및 공유 센터 → 이더넷 → 속성 → IPv4 → 다음 IP 주소 사용
    • IP 주소: 192.168.1.11  |  서브넷 마스크: 255.255.255.0  |  게이트웨이: 192.168.1.1
  3. 생존 신호(Ping) 확인: cmd 창에 아래 명령어 입력 → 시간<1ms 뜨면 물리 연결 100% 성공!
    ping 192.168.1.10
  4. 통신 테스트: 2_PC_B_클라이언트실행(EnetClient).bat 실행 → PLC IP(192.168.1.10), 포트 2004 입력 → [🔌 연결] → %MW0 [📥 읽기 요청] 클릭!
  5. 안 되거나 값이 다르면 우측 하단 [📋 카톡 전달용 로그 복사]를 눌러 그대로 공유해 주세요.
STEP 4 (선택)

22채널 3D 전체 관제 화면도 노트북에서 띄우기

현장 인터넷이 안 될 때도 3D 가스통 관제 화면을 직접 시연하려면, 출발 전 인터넷 되는 곳에서 딱 한 번 아래 명령어를 실행해 두세요.

cd 22ch-PLC npm install npm run dev:all

실행 후 브라우저에서 http://localhost:3000 접속! (한 번 npm install 해두면 현장 오프라인에서도 npm run dev:all로 바로 켜집니다.)
