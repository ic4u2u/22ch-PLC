SECTION 02

심층 재분석 : [거리 50M · 150M] 및 [4개 뱅크 사용 공장의 요구 변경] 해부

📡 1. 물리적 거리 재진단 (50M vs 150M 별도 공장)

  • 50M 구간 (방 A · 제1모니터실): 천장 우회 실거리가 약 60~65M가 됩니다. 완제품 60m 광HDMI 선은 꺾임 구간 입선 시 단선 위험이 있으므로, 얇은 CAT6 차폐선을 먼저 입선한 뒤 70~100M급 무전원 PoC 연장기(또는 미니PC)를 물리는 것이 시공성이 가장 뛰어납니다.
  • 150M 구간 (별도 공장 · 실포설 180~200M!): 일반 구리 랜선(CAT6)은 이더넷 표준 한계(100m)와 HDBaseT 영상 한계(150m)를 모두 초과합니다! 억지로 연결하면 화면 깜빡임·블랙아웃이 발생하며, 특히 서로 다른 공장 건물 간 구리선 직결은 낙뢰 유도전류로 양쪽 장비를 태웁니다.
  • 150M 정석 해법: 건물 간 이미 연결된 ① 사내 인트라넷망을 그대로 사용(배선비 0원)하거나, 선을 새로 깔 때는 유리섬유로 된 ② 옥외용 2코어 광점퍼코드(200M, 약 7만원) + 광 미디어 컨버터 1쌍(약 5만원)을 쓰면 2km까지 노이즈·낙뢰 피해 0%로 완벽 개통됩니다!

🧠 2. 운영 심리 진단 (“4뱅크 요구 → 11뱅크 모두 요청”의 숨은 함정!)

  • 현재 상황: 150M 공장은 실제로 4개 뱅크만 사용하지만, 담당자 입장에서는 “전체 가스실 현황도 다 같이 보자”며 11뱅크 전체 표출을 요구한 상태입니다.
  • 가동 1주일 뒤 벌어질 일 (알람 피로도 현상): 11뱅크가 똑같이 뜨면, 그 공장과 전혀 상관없는 나머지 7개 뱅크의 가스가 비거나 교체할 때마다 150M 공장 75인치 TV에서도 시뻘건 위험 경보가 번쩍입니다! 작업자들이 진짜 자기네 4개 뱅크 경보와 헷갈려 결국 “죄송한데 다시 우리 공장 쓰는 4개 뱅크만 크게 띄워주세요!”라고 재요청할 확률이 99%입니다.
  • 안전 권한 문제: 또한 4개 뱅크만 쓰는 공장에서 실수로 남의 공장 7개 뱅크 솔밸브를 잠그면 대형 공정 사고가 납니다. 따라서 150M 공장은 PIN 잠금이 걸린 읽기 전용 뷰(/?view=wallboard)로 띄우되, 언제든 11뱅크 전체 ↔ 4뱅크 전용을 소프트웨어 주소 한 줄로 바꿀 수 있는 [미니PC 방식]이 압도적으로 유리합니다!
SECTION 03

50M / 150M 조건별 3대 아키텍처 [장점(Pros) vs 단점(Cons)] 종합 분석

★ 제1안 (최우선 추천) : 거리·역할 맞춤형 하이브리드안 [50M 직결연장 + 150M 광/사내망 미니PC] 추가 장비비 약 35~42만 원 (사내망 활용 시 약 28만 원)
🔗 구성: 관리석(1.5M HDMI)  |  방 A(50M): 메인PC DP → 1:1 PoC 랜연장기(또는 광HDMI 50M)로 확장화면 직결  |  타공장 B(150M): 사내망(또는 200M 광점퍼코드+광컨버터) → 초소형 미니PC

👍 장점 (Pros)

  • 현재 요구(11뱅크 전체) + 미래 재변경(4뱅크 전용) 100% 동시 대응!: 지금 당장은 50M 방A와 똑같이 11뱅크 전체 화면을 띄워 납품하고, 나중에 150M 공장이 “다시 4뱅크만 보여달라”고 해도 추가 공사 없이 웹 주소만 바꿔 즉시 해결됩니다.
  • 50M 방 A의 미니PC 비용·관리 절감: 항상 11뱅크 전체만 보면 되는 50M 방 A는 메인 PC의 듀얼 모니터 확장 기능(start-dual-kiosk.bat)으로 바로 쏴주므로 미니PC 1대 값과 세팅 수고를 아낍니다.
  • 150M 장거리 화질 저하 0% & 낙뢰 완벽 방어: 광컨버터(또는 공장 간 기존 사내망)를 통해 디지털 패킷으로 전송하므로 200m가 넘어도 4K 원본 칼화질이 유지됩니다.
  • 타 공정 밸브 오조작 원천 방지: 150M 공장 미니PC는 전광판 전용 모드(버튼 없음 + PIN 번호 잠금)로 실행되어 타 공장 7개 뱅크를 절대 건드릴 수 없습니다.

👎 단점 및 주의사항 (Cons)

  • 선로 방식 이원화: 사내망을 안 쓰고 새로 선을 깔 경우, 50M 구간은 CAT6 차폐선, 150M 구간은 옥외용 2코어 광점퍼코드(완제품)로 자재를 구분해 포설해야 합니다. (단, 150M 구간을 구리 CAT6로 갈 경우 80m 중간 지점에 기가허브 1개를 두면 해결됩니다)
  • 윈도우 PC 총 2대 관리: 메인 서버 PC 외에 150M 공장에 초소형 미니PC 1대가 설치됩니다.
🎯 아키텍트 총평: 비용·안정성·150m 거리 돌파·향후 4뱅크 화면 분리 가능성까지 모든 리스크를 가장 적은 예산으로 완벽히 방어하는 실전 1순위 베스트 설계입니다!
🚀 제2안 (사내망 보유 시 최강) : 전 구간 IP 네트워크 통합안 [50M LAN 미니PC + 150M 광/사내망 미니PC] 추가 장비비 약 42~52만 원 (배선 공사비 대폭 절감!)
🔗 구성: 관리석(1.5M HDMI 단독)  |  방 A(50M): CAT6 랜선(또는 사내망) → 미니PC #1  |  타공장 B(150M): 사내망(또는 200M 광컨버터) → 미니PC #2

👍 장점 (Pros)

  • 사내 공유기/전산망 활용 시 50M + 150M 배선 공사비 전액 0원!: 방 A와 150M 공장 벽면에 이미 YG-ONE 사내 전산망 랜포트가 살아 있다면, 천장 전선관 공사를 단 1m도 하지 않고 미니PC 2대만 꽂아 즉시 개통할 수 있습니다!
  • 3개 공간 100% 독립 화면 & 마우스 이탈 방지: 메인 PC에는 관리용 모니터 1대만 연결되어 업무 중 마우스 커서가 외부 TV로 넘어가는 일이 없으며, 방 A와 공장 B 모두 각자 원하는 화면·음성경보를 독립 설정할 수 있습니다.

👎 단점 및 주의사항 (Cons)

  • 미니PC 2대 구입비: 제1안보다 미니PC 1대 비용(약 18~20만 원)이 더 들어갑니다.
  • 단말기 3대 초기 세팅: 메인 서버 PC + 미니PC 2대에 각각 크롬 전체화면 자동실행(Kiosk) 시작프로그램 등록이 필요합니다.
🎯 아키텍트 총평: 두 장소에 이미 사내 인터넷 랜포트가 나와 있다면 수백만 원짜리 배관 인건비를 통째로 아낄 수 있어 실제 총공사비가 가장 저렴해지는 최고의 방법입니다!
🔶 제3안 (단순 복제형) : 대표님 손그림 구상의 150M 생존 수정안 [단일PC + 50M 랜연장 + 150M 광HDMI 연장] 추가 장비비 약 38~48만 원
🔗 구성: 관리석(1.5M HDMI)  |  메인PC DP(Active젠더) → [Loop-out 내장 광HDMI 송신기] ➔ ① 광케이블 200M → 광수신기 RX → 150M 공장 TV  /  ② Loop-out → 50M PoC 랜연장기 → 방A TV

👍 장점 (Pros)

  • 윈도우 PC 1대만 관리: 외부 모니터 뒤에 미니PC가 전혀 없으므로 메인 서버 PC 1대만 관리하면 됩니다.
  • 현재 요구(“똑같이 11뱅크 표시”) 즉시 충족: 50M 방 A와 150M 공장에 100% 동일한 11뱅크 숫자 전광판 화면을 복제 송출합니다.

👎 단점 및 치명적 리스크 (Cons)

  • 향후 “다시 4개 뱅크만 보여달라” 재요청 시 대응 완전 불가!: 하드웨어 신호 복제 방식이므로 150M 공장 모니터만 따로 4개 뱅크로 줄여줄 방법이 없습니다. 재요청이 오면 연장기를 철거하고 미니PC로 다시 깔아야 합니다.
  • 구리 랜선 일체형 연장기 사용 불가 (비용 상승): 150M(실포설 180~200M) 거리 때문에 저렴한 랜선 분배연장기를 못 쓰고 고가의 산업용 광(Fiber) HDMI 연장기 세트 + 50M 연장기를 조합해야 하므로 장비비가 미니PC 방식(제1안)보다 오히려 더 비싸집니다!
  • 원격 마우스 조작 및 기존 사내망 경유 불가: 오직 눈으로 시청만 가능하며 반드시 전용 선로를 새로 깔아야 합니다.
